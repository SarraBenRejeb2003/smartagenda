# SmartAgenda 📅🤖

**SmartAgenda** is an intelligent mobile application designed to simplify appointment management through a user-friendly interface and an AI-powered conversational assistant.

Developed with **Flutter and Dart**, the application combines local data management with Google's Gemini AI to provide a smarter way to organize and interact with appointments.

---

## 📌 Overview

Managing appointments manually can be time-consuming and may lead to scheduling conflicts or forgotten events.

SmartAgenda provides a centralized mobile solution that allows users to manage appointments, organize professional and doctor information, receive reminders, and interact with their data using natural language.

The application integrates **Gemini through Firebase AI Logic**, using Function Calling to connect the AI assistant with the application's actual data and operations.

## 🏗️ Architecture

SmartAgenda follows a layered architecture to separate the user interface, application logic, business operations, and data persistence.

```text
lib/
│
├── main.dart
│
├── models/
│   └── rendez_vous.dart
│
├── views/
│   ├── accueil/
│   ├── rendez_vous/
│   ├── professionnels/
│   ├── docteurs/
│   ├── calendrier/
│   ├── parametres/
│   └── smart_assistant/
│
├── viewmodels/
│
├── repositories/
│
├── services/
│
├── database/
│
├── app_localizations.dart
└── app_settings.dart
```

*Note: This is a conceptual representation of the project organization. Folder names should be adjusted if the actual repository uses a different structure.*

### Application data flow

```text
User Interface
      |
      v
   ViewModel
      |
      v
  Repository
      |
      v
 DatabaseHelper
      |
      v
    SQLite
```

### AI Assistant data flow

```text
User Question
      |
      v
Smart Assistant Interface
      |
      v
Smart Assistant ViewModel
      |
      v
Gemini Service
      |
      v
Firebase AI Logic
      |
      v
Gemini Function Calling
      |
      v
Dart Application Functions
      |
      v
Repository / SQLite
      |
      v
Gemini Response
      |
      v
User Interface
```

This architecture allows Gemini to interact with application data through controlled application functions rather than accessing the SQLite database directly.

## 🚀 Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your GitHub repository URL.

### 2. Navigate to the project directory

```bash
cd smart_agenda
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Configure Firebase

SmartAgenda uses Firebase AI Logic to communicate with Gemini.

To configure Firebase:

1. Create or select a project in the [Firebase Console](https://console.firebase.google.com/).
2. Register your Android application.
3. Configure Firebase for the Flutter project.
4. Add the required Android Firebase configuration file.
5. Enable Firebase AI Logic and configure the required services.
6. Verify that the Firebase configuration matches the Android application ID.

**Important:** Do not commit private credentials, service-account files, debug tokens, or other sensitive configuration data to GitHub.

### 5. Connect an Android device

Enable USB debugging on your Android device, connect it to your computer, and verify the connection:

```bash
flutter devices
```

### 6. Run the application

```bash
flutter run
```
